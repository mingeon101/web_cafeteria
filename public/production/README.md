# 급식 준비 현황

배포 후 `/production/`에서 열 수 있습니다. GitHub Pages에서는 `/web_cafeteria/public/production/`입니다. 서비스 바로가기와 관리자 대시보드에도 링크가 있습니다.

- 날짜·중식/석식·학년별 선주문 인원, 대기/완료 인원, 메뉴별 배식 횟수와 학년·반별 현황을 실시간으로 표시합니다.
- 기존 `preorders/{YYYY-MM-DD}`, `preorders/{YYYY-MM-DD}__dinner`를 읽습니다. 학생별 복제 기록을 중복 합산하지 않습니다.
- pending/fulfilled 주문량을 포함합니다. 상태 없는 이전 기록은 대기로 보고, 취소·0회·잘못된 신청은 제외하고 건수를 표시합니다.
- 숫자는 인분이나 무게가 아닌 메뉴별 배식 횟수입니다. 식재료 무게, 여유분, 현장 예상 인원을 입력하거나 적용하는 기능은 없습니다.
- 기존 준비량 설정을 불러오지 않으며, 삭제된 입력 요소에 접근하지 않습니다.
- 신청 당시 메뉴를 우선 표시하고, 서로 다른 메뉴가 있으면 안내합니다.
- CSV·인쇄, 조회 오류·오프라인 안내, 모바일 화면을 지원합니다.
- 기존 Firebase 읽기만 사용합니다. 데이터베이스와 보안 규칙은 변경하지 않으며 학생 이름·ID·이메일은 화면/CSV에 표시하지 않습니다.

집계 검사: `node --test tests/production-core.test.mjs`
