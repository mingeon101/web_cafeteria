학생 전용 뷰어 — 나의 급식

student-view.html을 열거나 식판 인식 페이지 상단의 나의 급식을 누릅니다.
관리 페이지 상단의 학생 뷰어 링크로도 열 수 있습니다.

사용 방법
1. 학년·반·번호를 입력하고 내 기록 보기를 누릅니다.
2. 기간별 평균 잔반 면적, 측정 식사 횟수와 날짜별 기록을 확인합니다. 기간 조회는 최대 31일입니다.
3. 공개된 이벤트의 보상·기간·조건과 나의 측정 횟수, 평균 잔반, 조건 달성 여부를 확인합니다.
4. 관리자가 지급 완료를 기록하면 보상 지급 상태와 지급일을 볼 수 있습니다.
5. 학생 변경을 누르면 이전 학생의 기록과 지급 상태가 화면에서 지워집니다.

Firebase 읽기 전용
- 학생 고유 ID 조회는 학년·반·번호 lookupKey와 기존 grade/classNo/classNum/number를 사용합니다.
- 잔반 기록은 선택한 학생의 students/학생ID/wasteReports에서만 조회합니다.
- 이벤트 지급 기록도 cafeteriaWasteEventRewards/이벤트ID/선택한학생ID에서만 조회합니다.
- 임시 저장 이벤트는 표시하지 않습니다. 공개된 활성·종료 이벤트만 표시합니다.
- 이벤트 생성·수정·보상 지급 버튼과 Firebase 쓰기 요청은 없습니다.
- 학생 선택 정보는 브라우저 저장소에 보관하지 않습니다.
- 학년·반·번호는 학생 구분 입력입니다. 별도 로그인이나 본인 인증을 추가하지 않았으며 기존 Firebase 보안 규칙이 적용됩니다.
- 개인 이벤트 판정은 현재 조회 시점의 기록으로 계산하며 관리자의 대상자 판정과 같은 집계 방식을 사용합니다.

학생 뷰어 추가로 기존 인식·설정 탭과 관리자 이벤트 운영 기능은 유지됩니다.
실제 Firebase 기록에 테스트 데이터를 쓰지 않았습니다.
