급식 이벤트 관리

events.html을 열거나 식판 인식 페이지의 설정 → 급식 이벤트 관리를 누릅니다.

잔반 통계
- 시작일과 종료일을 정하고 통계 조회를 누릅니다. 한 번에 최대 31일입니다.
- 평균 잔반 면적, 참여 학생, 측정 식사 수, 날짜별·칸별·학생별 통계를 표시합니다.
- 데이터 원본은 students/학생ID/wasteReports/날짜/기록ID입니다.
- 학생별 같은 날짜 기록은 마지막 한 건만 사용합니다. 기록이 없는 학생은 포함하지 않습니다.
- 학생 전체 프로필·PIN·얼굴 정보를 내려받지 않습니다. 잔반 기록과 학년·반·번호 lookupKey만 읽습니다.

이벤트 운영
1. 이벤트 탭에서 이름, 보상, 기간, 평균 잔반 기준, 최소 측정 횟수, 안내를 입력합니다.
2. 이벤트 임시 저장 → 이벤트 열기를 누릅니다.
3. 대상자 확인으로 현재 조회 시점의 측정 기록에 따라 조건 충족 학생을 확인합니다.
4. 실제 보상을 전달한 다음 지급 완료를 누릅니다. 저장 시 최신 측정 기록을 다시 확인합니다.
5. 이벤트 종료를 누르면 이벤트 상태가 종료로 바뀝니다. 종료 후에도 미지급 보상을 기록할 수 있습니다.
- 예: 기간 내 평균 잔반 10% 이하, 2회 이상 측정 → 디저트 1개.
- 활성화한 이벤트는 조건을 수정하지 않습니다. 다른 조건은 새 이벤트로 만드세요.
- 지급 완료는 학생당 이벤트별로 한 번만 저장하며 서버의 조건부 쓰기로 동시 중복을 막습니다.
- 지급 판정에 사용한 기록 ID, 평균, 조건, 시점을 함께 저장합니다.

Firebase 경로
이벤트: cafeteriaWasteEvents/이벤트ID
지급 기록: cafeteriaWasteEventRewards/이벤트ID/학생ID
새 경로에도 기존 Firebase 읽기·쓰기 보안 규칙이 적용됩니다. 권한 오류는 화면에 표시됩니다.
잔반 통계는 사진에서 추정한 면적이며 무게나 실제 섭취량이 아닙니다.
실제 학생·이벤트·지급 기록에 테스트 데이터를 쓰지 않았습니다.
