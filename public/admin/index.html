학생별 영양리포트

학생별 배식 기록과 Google Sheets 영양정보를 바탕으로 AI가 작성합니다. 학생을 선택하면 개인 리포트를 직접 작성할 수 있습니다. 저장한 리포트만 학생에게 공개됩니다.

오늘의 메뉴와 각 학생의 배식 기록(serve)을 Firebase에서 불러옵니다. AI 작성 시 최신 값을 다시 읽으며, 제공량이 없으면 임의로 계산하지 않습니다.

1회 기준: 밥·국 200–250g → 225g / 김치·부찬 40–50g → 45g / 주찬 100–120g → 110g
배식 횟수 × 중간값으로 추정합니다. 1인분 기준 시트는 위 1회 중량과 같은 기준일 때만 선택하세요.

학생 리포트 이메일 발송

리포트를 저장한 뒤 수신자 이메일을 입력해 메일 양식을 만들고, 내용을 확인한 다음 발송하세요.

주소를 비우면 현재 페이지를 기준으로 자동 생성합니다. 배포 주소가 다르면 이 칸에 학생 리포트 페이지 주소를 입력하세요.

확인되지 않은 영양값은 비워두세요. 수동 입력값으로 그래프가 갱신됩니다.
